## 💡 The Story Behind the Project
I built this project out of a personal need. I needed a way to jot down notes while simultaneously keeping track of time. I wanted to avoid the hassle of constantly switching back and forth between two different apps on my phone. To solve this, I created this web app—an all-in-one, mobile-friendly solution that keeps your productivity flowing.

## ✨ Features

* **Dual Modes:** Seamlessly switch between a Notes interface and a Timer interface.
* **Picture-in-Picture Time (NowBar):** A floating widget allows you to keep an eye on your running timer even while you are typing notes.
* **Advanced Timer functionality:** * Toggle between a **Stopwatch** (count up) and a **Countdown Timer**.
    * Timestamping support to mark laps or specific moments.
* **📱 Mobile-First & Intuitive Gestures:** Optimized for touch devices.
    * *Swipe up/down* to edit timer values.
    * *Swipe right* to create a timestamp.
    * *Long press* on a note to edit it.
* **💻 Desktop Support:**
    * *Spacebar* to create a timestamp.
    * *Double-click* to edit notes.
* **🌗 Dark & Light Themes:** Fully responsive custom UI themes that respect your eyes.
* **💾 Local Storage:** Your notes, current theme, and layout preferences are automatically saved in the browser.

## 🛠️ Technologies Used

* **Vanilla JavaScript (ES6+):** For handling states, UI rendering, local storage, and gesture detection.
* **CSS3:** Custom variables, advanced keyframe animations, dynamic conic-gradients, and responsive design.
* **HTML5:** Semantic structure.
